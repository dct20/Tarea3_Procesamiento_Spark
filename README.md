# Tarea3_Procesamiento_Spark
Este proyecto se realizó como parte del curso Big Data de la Universidad Nacional Abierta y a Distancia (UNAD). Su propósito es practicar el procesamiento y análisis de datos utilizando Python y Apache Spark.

**Problema seleccionado**

Se busca identificar los productos que generan mayores ingresos y comparar los resultados de las categorías de papelería y tecnología.
**Herramientas utilizadas**
Google Colab.
Python.
Apache Spark y PySpark.
Pandas y Matplotlib para apoyar la visualización.
GitHub para publicar el código.
**Ejecución**
El archivo Tarea3_Procesamiento_Spark.ipynb contiene el código y las celdas de la práctica. Se puede abrir con Google Colab y ejecutar las celdas en orden.
**Resultados**
El análisis permite calcular los ingresos por producto y categoría, revisar los datos y generar una gráfica comparativa.
